// 01 — MANIFESTO

The internet broke.
We built around it.

Every "decentralized" project still phones home. A domain registrar. A cloud bucket. An API key that can be revoked at 3 AM by someone you've never met.

MossyMesh starts from a different premise: assume the infrastructure is hostile or gone. No central DNS. No cloud database as control plane. No single point that a government, a corporation, or a backhoe can take out.

What remains is a mesh of ordinary devices — phones, Pis, PCs, LoRa radios — routing by cryptographic identity, executing deterministic WASM jobs, and converging on shared state through CRDTs. The ledger on any edge node stays under 10 MB. Outputs are verifiable or they don't count.

01

Identity-routed

Ed25519 keys are addresses. No IP dependence, no DNS lookup, no registrar to seize.

02

Deterministic WASM

Jobs run in a sandboxed WASM runtime. Same input, same output, on every device — verifiable by anyone.

03

Offline-first

Designed for dead zones, disaster zones, and censored zones. The mesh is the network.

04

Tiny ledger

≤10 MB active ledger on edge hardware. A Raspberry Pi Zero can be a full citizen.

// 03 — PROOF, NOT PROMISES

Chess across the mesh.
Same board, every device.

Click a piece, then a square. Moves publish to the mesh.

If two phones in airplane mode can agree on a chess position, they can agree on anything.

The Chess PoC is MossyMesh's determinism benchmark: every move is a CRDT operation, every position is a trie root, and the engine evaluation runs identically on-device or in the WASM sandbox. Target: ~836 million nodes per second.

  • Deterministic state — identical FEN on every peer, or the merge is wrong
  • Verifiable compute — <1% unverifiable outputs, or the job doesn't ship
  • Hostile RF — <5% job timeout even on flaky LoRa links
